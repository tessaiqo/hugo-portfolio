## 1. Пошаговый анализ кода

Исходный код:

```javascript
console.time('a');
((y = 2 ** 14 , x = Date.now()) => {
    while (Date.now() - x < y) ;
})();
console.timeEnd('a');
```
### 1.1 **`console.time('a')`**
Метод `console.time()` запускает таймер с указанной меткой `('a')`. Внутренний счётчик начинает отсчёт времени с момента вызова.

### 1.2 IIFE с оператором запятой в параметрах
```javascript
((y = 2 ** 14 , x = Date.now()) => { ... })();
```

- **IIFE (Immediately Invoked Function Expression)** — функциональное выражение, которое объявляется и немедленно вызывается.
- В списке параметров стрелочной функции используется оператор **запятая (`,`)**. Он выполняет оба выражения слева направо, возвращая результат последнего (в данном случае `x = Date.now()`).
- `y = 2 ** 14` — присваивание переменной `y` значения `2` в степени `14`, то есть `16384`.
- `x = Date.now()` — присваивание переменной `x` текущего времени в миллисекундах с начала **Unix-эпохи** (1 января 1970 года, 00:00:00 UTC).

Поскольку перед `y` и `x` нет ключевых слов `let`, `const` или `var`, в нестрогом режиме они становятся **глобальными переменными** (свойствами объекта `window` в браузере или `global` в Node.js).

### 1.3 Тело функции: активное ожидание
```javascript
while (Date.now() - x < y) ;
```
- `Date.now() - x` — вычисляет, сколько миллисекунд прошло с момента сохранения значения в `x`.
- Цикл `while` с пустым телом (`;`) повторяется до тех пор, пока эта разница меньше `y` (16384 мс).
- Таким образом, выполнение потока **блокируется** примерно на **16,384 секунды**. Это называется **активным ожиданием (busy wait)**.

### 1.4 `console.timeEnd('a')`
Метод останавливает таймер с меткой `'a'` и выводит в консоль прошедшее время в миллисекундах, например:
`a: 16384.123ms`


## 2. Ответы на вопросы задания
### 2.1 Откуда берётся переменная `x` и какое у неё значение?
Переменная `x` создаётся **в момент вызова IIFE** внутри списка параметров. Ей присваивается результат вызова `Date.now()` — **текущее количество миллисекунд, прошедших с 1 января 1970 года 00:00:00 UTC** (Unix-эпоха). Из-за отсутствия объявления через `let`/`const`/`var` она становится глобальной переменной.

### 2.2 Переписывание без использования IIFE
Ниже приведён эквивалентный код, записанный в императивном стиле без IIFE:
```javascript
console.time('a');

let y = 2 ** 14;      // 16384
let x = Date.now();

while (Date.now() - x < y) {
    // пустой цикл — активное ожидание
}

console.timeEnd('a');
```
**Проверка эквивалентности:**

- Таймер стартует перед ожиданием.
- Длительность задержки та же (16384 мс).
- Результат `console.timeEnd` совпадает.
- Единственное отличие: в новой версии переменные `x` и `y` объявлены с `let` и находятся в блочной области видимости, тогда как в оригинале они были глобальными (что не влияет на логику работы).

### 2.3 Результат выполнения

При запуске кода в консоли браузера или среде Node.js `console.timeEnd('a')`выводит значение, близкое к **16384** миллисекунд.
Целое количество секунд составляет: **16**

## 3. Дополнительная справка: Unix-эпоха
**Почему `Date.now()` возвращает время с 1 января 1970 года?**
- **Unix-эпоха** — начало отсчёта системного времени в операционной системе Unix, зафиксированное на полночи 1 января 1970 года по UTC.

- Это решение было принято в начале 1970-х годов разработчиками Unix для удобства хранения времени в виде целого числа секунд.

- Стандарт POSIX закрепил эту точку отсчёта, и все современные языки программирования (C, Python, Java, JavaScript) следуют данному соглашению.

- В JavaScript метод `Date.now()` возвращает **миллисекунды** с Unix-эпохи, что обеспечивает высокую точность измерений.
